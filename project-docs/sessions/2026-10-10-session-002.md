### Design Summary

**Instance Entity (`Instance.h`/`Instance.cpp`):**

```cpp
class Instance {
    QUuid id;                           // Primary key (DEC-002)
    QString name;                       // User-editable display name
    bool enabled = true;                // Instance active state
    CoreType core_type = CoreType::Xray; // Xray/SingBox/External (DEC-007)
    InstanceCoreConfig core_config;     // Core-specific overrides
    int socks_port = 10808;             // SOCKS proxy port
    int http_port = 10809;              // HTTP proxy port
    int api_port = -1;                  // Management API port (optional)
    QString bind_address = "127.0.0.1"; // Bind address
    bool auto_start = false;            // Auto-start on launch
    bool restart_on_crash = false;      // Auto-restart on crash
    bool restore_last_profile = true;   // Restore last profile
    int startup_delay_ms = 0;           // Staggered start delay
    int last_profile_id = -1;           // Last selected profile
    int last_active_profile_id = -1;    // Last active profile
    InstanceDNSSettings dns_settings;   // Per-instance DNS overrides
    qint64 created_at = 0;              // Creation timestamp
    qint64 updated_at = 0;              // Last modification timestamp
};
```

**Supporting Types:**
- `CoreType` enum: `Xray=0`, `SingBox=1`, `External=2`
- `InstanceCoreConfig`: `core_path`, `core_args`, `core_config_json`
- `InstanceDNSSettings`: 15+ DNS/routing fields matching Throne's SettingsRepo

**Key Methods:**
- `CreateDefault()` - Factory for default instance
- `ToJson()` / `FromJson()` - Full JSON serialization
- `IsValid()` / `Validate()` - Validation with error messages
- `Touch()` - Updates `updated_at` timestamp
- `operator==` / `operator!=` - UUID-based equality
