### Schema Changes (via Migration)

1. **`instances` table** - UUID TEXT PK, all Instance fields, created_at/updated_at timestamps
2. **`instance_settings` table** - (instance_id, key, value) composite PK, FK to instances with CASCADE DELETE
3. **`port_allocations` table** - (instance_id, port_type) PK, unique index on port for conflict detection
4. **`groups.instance_id` column** - Added via ALTER TABLE, populated with Default Instance UUID

### Migration Logic (`src/database/Migration.cpp`)

- **Detection**: Checks for missing `instances` table or migration version ≠ "1"
- **Transaction-wrapped**: All operations in BEGIN IMMEDIATE ... COMMIT with rollback on failure
- **Idempotent**: Safe to run multiple times (CREATE TABLE IF NOT EXISTS, INSERT OR REPLACE)
- **Default Instance**: Generates UUID v4, name="Default", core_type="xray" (DEC-007)
- **Data Migration**:
  - All existing Groups → Default Instance (instance_id column added)
  - Global settings → instance_settings for Default Instance (filtering global-only keys)
  - Default ports allocated: SOCKS 10808, HTTP 10809, API 10810
- **Version Tracking**: Stores "coredeck_migration_version" = "1" in settings table
- **Backward Compatibility**: Throne ignores new tables/columns, can still read DB

### InstanceRepository CRUD (`src/database/InstanceRepository.cpp`)

| Method | Description |
|--------|-------------|
| `getById(QUuid)` | Fetch single instance by UUID |
| `getByName(QString)` | Fetch single instance by name |
| `getAll()` | All instances (unordered) |
| `getAllOrdered()` | All instances ordered by created_at |
| `save(Instance)` | INSERT or UPDATE with thread-safe WriteMutex |
| `remove(QUuid)` | DELETE instance (CASCADE deletes settings, ports) |
| `exists(QUuid)` | Check existence |
| `count()` | Total instance count |
| `getDefaultInstance()` | First instance by created_at |
| `getAutoStartInstances()` | Auto-start instances ordered by startup_delay_ms |

- Thread-safe via `Database::WriteMutex()`
- Parameterized SQL queries (no string interpolation)
- JSON serialization for nested structs (dns_settings, core_config)
- CoreType enum ↔ string conversion consistent with Instance entity
